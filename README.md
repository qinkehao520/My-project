# Unity 2D Game Demo
## 项目简介
基于Unity引擎开发的2D小游戏，完成游戏场景搭建、角色移动、碰撞检测、UI交互等基础游戏功能。

## 技术栈
- Unity 2D
- C#
- Sprite精灵、Tilemap瓦片地图
- 简单UGUI游戏界面

## 实现功能
1. 角色控制：键盘控制角色移动、动画切换
2. 碰撞系统：物体碰撞检测，触发事件
3. 场景搭建：Tilemap搭建2D游戏地图
4. UI界面：游戏开始、暂停、得分面板
5. 资源管理：精灵素材管理，预制体复用

## 运行方式
1. 使用对应版本Unity打开项目
2. 在Project窗口打开游戏主场景
3. 点击Play按钮运行，键盘控制角色

## 项目总结
练习Unity 2D基础开发，熟悉C#脚本编写、预制体、精灵与瓦片地图使用，掌握Git进行项目版本管理。
